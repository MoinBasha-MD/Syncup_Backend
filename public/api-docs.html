Authentication

User registration, login, and authentication management

POST /api/auth/register 🌐 Public
📝 Description
Register a new user account with phone number, username, and optional profile details.
📥 Request Body
  • phoneNumber string required

    User's phone number (must be unique)

  • username string required

    Desired username (must be unique)

  • firstName string

    User's first name

  • lastName string

    User's last name

📤 Response
{
  "success": true,
  "message": "User registered successfully",
  "data": {
    "user": {
      "_id": "507f1f77bcf86cd799439011",
      "phoneNumber": "+1234567890",
      "username": "john_doe",
      "firstName": "John",
      "lastName": "Doe"
    },
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
  }
}
POST /api/auth/login 🌐 Public
📝 Description
Authenticate user and receive JWT token. Rate limited to 5 attempts per 15 minutes.
📥 Request Body
  • phoneNumber string required

    User's registered phone number

📤 Response
{
  "success": true,
  "data": {
    "user": { /* user object */ },
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
  }
}
🔗 Dependencies
→ Use token in Authorization header for protected routes
POST /api/auth/check 🌐 Public
📝 Description
Check if a phone number or username already exists in the system.
📥 Request Body
  • phoneNumber string

    Phone number to check

  • username string

    Username to check

Users & Profile Management

User profile management, contacts, status updates, and user data operations

GET /api/users/profile 🔒 Auth Required
📝 Description
Get the authenticated user's complete profile information including status, settings, and preferences.
🔑 Headers
  • Authorization string required

    Bearer {token}

📤 Response
{
  "success": true,
  "data": {
    "_id": "507f1f77bcf86cd799439011",
    "phoneNumber": "+1234567890",
    "username": "john_doe",
    "firstName": "John",
    "lastName": "Doe",
    "bio": "Tech enthusiast",
    "profileImage": "/uploads/profile-images/...",
    "currentStatus": { /* status object */ }
  }
}
PUT /api/users/profile 🔒 Auth Required
📝 Description
Update user profile information including name, bio, and settings.
📥 Request Body
  • firstName string

    Updated first name

  • lastName string

    Updated last name

  • bio string

    User bio/description

POST /api/contacts/sync 🔒 Auth Required
📝 Description
Sync device contacts with the server. Rate limited to prevent abuse.
📥 Request Body
  • contacts array required

    Array of contact objects with phoneNumber, name, etc.

POST /api/status-management/current 🔒 Auth Required
📝 Description
Set or update the user's current status (availability, mood, activity).
📥 Request Body
  • status string required

    Status text/message

  • emoji string

    Status emoji

  • expiresAt date

    When status should expire

🔗 Related Endpoints
GET /api/status/history GET /api/status/templates DELETE /api/status-management/current
GET /api/users/:userId/data/export 🔒 Auth Required
📝 Description
Export all user data for GDPR compliance (account, posts, messages, etc.).
📤 Response
Returns a JSON file with complete user data archive.

Social Features

Messaging, groups, friends, connections, stories, and social interactions

POST /api/chat/messages 🔒 Auth Required
📝 Description
Send a direct message to another user. Supports text, media, and encrypted content.
📥 Request Body
  • recipientId string required

    User ID of message recipient

  • content string required

    Message text content

  • mediaUrl string

    URL to attached media (image, video, file)

  • replyTo string

    Message ID if replying to another message

🔗 Related Endpoints
GET /api/chat/messages/:chatId DELETE /api/chat/messages/:messageId PUT /api/chat/messages/:messageId/read
⚡ Real-time
Messages are delivered via Socket.IO for instant delivery. WebSocket event: new_message
POST /api/group-chats 🔒 Auth Required
📝 Description
Create a new group chat with multiple participants.
📥 Request Body
  • name string required

    Group chat name

  • participants array required

    Array of user IDs to add to group

  • groupImage string

    Group profile image URL

POST /api/friends/request 🔒 Auth Required
📝 Description
Send a friend request to another user.
📥 Request Body
  • userId string required

    ID of user to send friend request to

🔗 Related Endpoints
POST /api/friends/accept/:requestId DELETE /api/friends/:friendId GET /api/friends/list
POST /api/stories 🔒 Auth Required
📝 Description
Create a new story (24-hour temporary content with image/video).
📥 Request Body
  • mediaUrl string required

    URL to story media (image or video)

  • caption string

    Optional story caption

  • privacy string

    Privacy setting: "public", "friends", "custom"

⏱️ Auto-deletion
Stories automatically expire and delete after 24 hours.
POST /api/posts 🔒 Auth Required
📝 Description
Create a new social post with text, images, videos, or polls.
📥 Request Body
  • content string required

    Post text content

  • media array

    Array of media URLs (images/videos)

  • hashtags array

    Array of hashtags

  • mentions array

    Array of mentioned user IDs

🔗 Related Endpoints
GET /api/posts/feed POST /api/posts/:postId/like POST /api/posts/:postId/comment DELETE /api/posts/:postId

Location & Maps

Location sharing, meetups, places, and geolocation services

POST /api/location-sharing 🔒 Auth Required
📝 Description
Share real-time location with selected users or groups with time limits and privacy controls.
📥 Request Body
  • latitude number required
  • longitude number required
  • sharedWith array required

    Array of user IDs to share location with

  • duration number

    Duration in minutes (default: 60)

POST /api/meetups 🔒 Auth Required
📝 Description
Create meetup with shared destination and group live tracking.
📥 Request Body
  • destination object required

    Destination coordinates and name

  • participants array required

    Array of user IDs invited to meetup

GET /api/places/nearby 🔒 Auth Required
📝 Description
Get nearby places using Geoapify integration with caching.
📥 Query Parameters
  • lat number required
  • lon number required
  • radius number

    Search radius in meters (default: 1000)

  • category string

    Place category filter

Media & Files

File uploads, music library, video streaming, and encrypted files

POST /api/upload 🔒 Auth Required
📝 Description
Upload files (images, videos, documents). Supports multipart/form-data with file size limits.
📥 Request
  • file file required

    File to upload (multipart/form-data)

  • type string

    "image", "video", "document", "profile", "story"

📤 Response
{
  "success": true,
  "url": "/uploads/post-media/file_12345.jpg",
  "mediaToken": "signed_token_here"
}
⚠️ Limits
  • Images: 10MB max
  • Videos: 200MB max
  • Documents: 50MB max
GET /api/music 🔒 Auth Required
📝 Description
Browse music library with trending songs, genres, and streaming support.
POST /api/blobs 🔒 Auth Required
📝 Description
Upload encrypted ciphertext blobs for end-to-end encrypted content.
🔒 Security
Server stores only encrypted data. Decryption keys never leave client devices.
